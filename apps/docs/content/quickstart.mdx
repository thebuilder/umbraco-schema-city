## Requirements

| Requirement | Version |
| --- | --- |
| Umbraco | 17 or 18, tested on 17.6.2 and 18.1.1 |
| .NET | 10 |
| Backoffice user | Access to the Settings section |

## Install

```sh
dotnet add package TheBuilder.SchemaCity
```

Restart the site. The package needs no migration and adds nothing to your schema.

## Open the city plan

Open **Settings > Advanced > Schema City**. It opens on the city plan: a card for each type, in a district for each type allowed at root, framed at a zoom where names read. A big schema opens at its top left, and the **Overview** in the bottom-right corner shows the rest.

Every Document Type editor also gets a **Relationships** tab. It opens the plan focused on that type and its neighbours.

## Turn off the Relationships tab

The tab is on by default. To leave it out of the Document Type editor, set `RelationshipsTab` to `false` in `appsettings.json` and restart the site:

```json appsettings.json
{
  "SchemaCity": {
    "RelationshipsTab": false
  }
}
```

Schema City under **Settings > Advanced** stays either way. As with any appsettings value, an environment variable can set it too: `SchemaCity__RelationshipsTab=false`.

## First steps

<Steps>
  <Step title="Find a type">
    Press <kbd>⌘</kbd> <kbd>K</kbd> or <kbd>Ctrl</kbd> <kbd>K</kbd> and search by name, alias or property alias.
  </Step>
  <Step title="Look at its neighbourhood">
    Click its card to open the inspector, then double-click the card to focus on the types it connects to.
  </Step>
  <Step title="Check the schema">
    Open **Findings** in the header to see what the checks flag across the schema. See [Review findings](/findings).
  </Step>
  <Step title="Trace a change">
    Press <kbd>I</kbd> with a type selected to see every type a change to it reaches. See [Trace the impact of a change](/impact).
  </Step>
</Steps>

Press <kbd>?</kbd> for every control, or read [Navigate the city plan](/navigation).

To look around before you install, [try the demo](https://schema-city-demo.thebuilder.dk). It runs in the browser with a sample schema and needs no Umbraco install.
